# Sales report FY 2014-17 Data Analysis(Interactive Dashboard creation using MS excel)
## Project Objective
This Project wants to create a Annual Sales Reporrt 2014-17.It involves logistics analysis, Customer segmentation, Geographic Sales Performance, Sales Forecasting.

## Dataset used
-<a href="https://github.com/Dwaipayan-2208/Data-Analysis-Dashboard/blob/main/Sales%20Report%20FY%202014-17%20Dashboard%20Project.xlsx">Dataset</a>

## Questions(KPIs)
Compare  Quantity per sub-category
Compare  Total Sales per Qtr/Year
Compare Quanity vs Segment
Compare Profit vs Region

## Dashboard Interaction
-< a href="https://github.com/Dwaipayan-2208/Data-Analysis-Dashboard/blob/main/Screenshot%20(1).png">View Dashboard</a>

## Process
Verify data for any missing values and anomalies, and sort out the same.
Made sure data is consistent and clean with respect to data type, data format and values used.
Created pivot tables according to the questions asked.
Merge all pivot tables into one dashboard and apply slicer to make dynamic.
